# Backend Plugins — Enterprise Features

The plugin system of `apps/api`: declarative, data-driven power-ups
(workflows, rules, KPIs, reliability) + the developer guide for writing
in-process plugins. Everything here is **data, not code** — hot-reloadable via
REST, no deploy.
