# Typography

The type system is defined by two fonts and a scale driven by Tailwind
utilities — no component code needed.

## Usage

```tsx
<h1 className="text-4xl font-semibold tracking-tight">Page title</h1>
<p className="text-sm text-muted-foreground">Helper text</p>
<code className="font-mono text-xs">npm run build</code>
```

Headings render with the sans font and tight tracking by default; override per
element with `font-*` utilities when needed.
